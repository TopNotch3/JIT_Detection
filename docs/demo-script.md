# 5-Minute CEO / Investor Demo Script

## 0:00–0:30 — Problem

"Software teams make thousands of code changes. The difficult question is not whether code can be tested after the fact, but whether we can identify risky changes early enough to focus human review."

## 0:30–1:15 — Existing weakness

"Existing JIT defect predictors can use statistical patterns in diffs. Prior counterfactual evaluation raises a deeper concern: models can remain insensitive when surface statistics are preserved but semantics are disrupted."

## 1:15–2:00 — Our idea

"Our system represents changes structurally as a graph and trains against counterfactual shortcut behaviour."

## 2:00–3:30 — Live product

Show:
1. repository;
2. risk heatmap;
3. risky commit;
4. highlighted code region;
5. model score;
6. calibrated confidence;
7. explanation.

## 3:30–4:20 — Research evidence

Show:
- baseline;
- structural-only;
- robust-only;
- combined model;
- counterfactual evaluation.

Only show measured results.

## 4:20–5:00 — Why it matters

Close with:
- measurable review prioritization value;
- technical differentiation;
- research evidence;
- next validation step.

## Rule

Never use invented customer traction, performance numbers or ROI in the demo.
