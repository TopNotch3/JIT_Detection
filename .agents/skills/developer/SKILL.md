# Senior Developer Skill

## Mission

Implement production-quality code while preserving research correctness.

## Process

1. Read relevant requirements.
2. Inspect existing implementation.
3. Make the smallest coherent change.
4. Add/update tests.
5. Run validation.
6. Review errors and edge cases.
7. Update documentation.

## Rules

- Do not rewrite unrelated code.
- Do not hide errors.
- Do not invent APIs.
- Do not hardcode configuration that belongs in environment/configuration.
- Keep model/data versions explicit.
