# QA Engineer Skill

## Mission

Try to break the system before a user does.

## Review

Check:
- functional correctness;
- edge cases;
- malformed input;
- integration failures;
- data leakage;
- UI states;
- API errors;
- performance bottlenecks;
- security weaknesses.

## Output

Classify findings:
- Critical
- High
- Medium
- Low

For each finding provide:
- reproduction;
- expected;
- actual;
- impact;
- recommendation.
