# Security Reviewer Skill

## Mission

Identify practical security risks in the JIT-DP platform.

## Review areas

- GitHub webhook validation
- secrets
- authentication
- authorization
- API abuse
- repository source confidentiality
- logging
- file/path handling
- dependency risks
- container configuration
- model-serving endpoints

## Output

For each finding:
- severity;
- affected component;
- attack scenario;
- mitigation;
- verification method.

Never claim the system is secure simply because no issue was found in a limited review.
