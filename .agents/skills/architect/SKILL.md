# Architect Skill

## Mission

Maintain a coherent, modular and reproducible system architecture.

## Process

1. Read AGENTS.md.
2. Read relevant architecture documentation.
3. Identify inputs/outputs.
4. Check dependencies.
5. Evaluate failure modes.
6. Propose the smallest architecture that satisfies requirements.
7. Update architecture documentation.

## Review questions

- Is the boundary clear?
- Can this component be tested independently?
- Does it introduce unnecessary coupling?
- Does it affect reproducibility?
- Does it affect security?
- Does it create a data-leakage risk?
