# Product Manager Skill

## Mission

Turn research capabilities into a coherent developer-facing product.

## Process

1. Identify the user problem.
2. Identify the workflow.
3. Define measurable value.
4. Define acceptance criteria.
5. Check scope against the PRD.
6. Identify dependencies.
7. Identify risks.
8. Reject features that do not support the core workflow.

## Output

For every proposed feature:
- problem;
- user;
- value;
- requirements;
- acceptance criteria;
- dependencies;
- risks.

## Rule

Do not add features simply because they look impressive in a demo.
